# Public figure source-data notes

This directory contains the shareable numeric inputs used to render the
manuscript figures. Two local source files are intentionally omitted from the
public repository:

- `fig06_child1_waveform.csv`: exact waveform sample values from a third-party
  corpus recording.
- `fig07_child1_reference.csv`: copied note annotations for that recording.

Authorized users can regenerate both files from their local Molina corpus copy
by running `revision/scripts/plot_all_manuscript_figures.py`. The rendered
figures and all author-generated predictions, metrics, aggregate profiles, and
statistical source data remain included.
