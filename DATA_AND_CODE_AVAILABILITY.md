# Data and code availability

## Code Availability

The Python implementation, formal experiment configuration, tests, figure
generation scripts, and derived result artifacts are intended for release at:

https://github.com/YIXINOWO/humming-melody-key-estimation

## Data Availability

The experiments use the public MTG-QBH/Molina monophonic humming corpus. The
original audio recordings and annotations are not redistributed by this work
and should be obtained from the original data source. Derived experimental
artifacts provided in this repository include summary tables, predicted note
files, nested-cross-validation fold records, compressed out-of-fold
probabilities/features, paper figures, and shareable figure source data. Exact
waveform samples and copied third-party reference annotations are excluded.

HumTrans audio, reference MIDI, split definitions, and distributed baseline
outputs must be obtained from the HumTrans upstream project. ROSVOT source code
and checkpoint weights must be obtained from the ROSVOT upstream project.

## Repository action

After uploading this folder, create a versioned GitHub release. Archiving that
release in a DOI-issuing repository such as Zenodo is recommended, but no DOI is
claimed until one has actually been assigned.
